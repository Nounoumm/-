# 课程讲义工坊网站

## 本地运行

使用 Node.js 24+。在仓库根目录安装网站依赖，将 `site/.env.example` 复制为 `site/.env`，填写所需配置后运行：

```text
npm --prefix site ci
npm --prefix site run dev
```

开发时打开 **http://localhost:5173**，后台默认监听 `127.0.0.1:4173`。`BASE_URL` 必须与浏览器地址的协议、主机、端口完全一致；`localhost` 与 `127.0.0.1` 不可混用。配置只由后台读取，不能给密钥加 `VITE_` 前缀。

## 账号与历史

- 游客可直接使用，讲义保存在当前浏览器的本机历史中。
- 邮箱注册并验证后，可用同一账号在电脑、手机、平板浏览器登录，访问账号私密历史。此账号不与 Harness 插件互通。
- 本机历史不会自动上传；用户主动勾选导入，原记录保留。重复导入同一记录不会创建重复讲义。
- 账号保存采用版本检查；另一设备更新时保留冲突，用户可下载比较、另存副本或读取云端版本。
- 每份保留最近 20 个修订版本；回收站保留 30 天，服务启动和每天执行过期清理。
- 每账号最多 200 份（含回收站），每份规格最多 1 MiB，总规格及修订版本最多 100 MiB。
- 发布到社区生成独立公开快照，修改私密讲义不会自动修改公开内容。登录后可管理自己的分享，匿名旧分享需原管理凭据才能认领。

## 邮件与安全配置

注册验证、找回密码需要 `SMTP_HOST`、`SMTP_PORT`、`SMTP_FROM`。服务商要求认证时，同时填写 `SMTP_USER` 和 `SMTP_PASSWORD`。465 端口使用隐式 TLS；587 通常使用 STARTTLS。默认 `SMTP_REQUIRE_TLS=true`，仅本机测试邮件中继才考虑关闭。邮件服务缺失或发送失败会返回 503，不会假装成功。

验证及重置链接有效期 30 分钟、仅可使用一次；登录会话最长 30 天。密码为 12–128 个字符，服务端存 Argon2id 哈希。会话放在 HttpOnly、SameSite Cookie，HTTPS 下使用 Secure；账号写入检查来源和 CSRF。密码重置撤销所有旧会话，普通退出只撤销当前设备。

## 独立网站部署

1. 设置 `NODE_ENV=production` 和 `BASE_URL=https://你的域名`；将网站与 `/api` 放在同一 HTTPS 域名下。
2. 设置邮件参数、`DEEPSEEK_API_KEY` 和 `ADMIN_API_KEY`；可用 `PYTHON_PATH` 指定已安装 `python-docx` 的 Python 3.12+。无模型密钥时生成会明确报错。
3. 设置 `DATABASE_PATH` 为持久化磁盘中的绝对路径。数据库包含私密讲义、账号凭据哈希和分享，备份应按私密数据保护。
4. 运行 `npm --prefix site run build`，再运行 `npm --prefix site run server`。后台提供构建后的页面；`vite preview` 仅用于预览，不能代替生产服务。
5. 配置 HTTPS 反向代理指向 `127.0.0.1:4173`；需要容器监听时显式设置 `HOST=0.0.0.0`。当前限频按直连地址或账号计算，未盲信转发地址头；代理后的匿名限频可能由多个用户共享。

当前存储适合单实例服务。不要给多个独立实例分别建立数据库，否则无法跨设备共用历史。数据库迁移自动运行；现有磁盘数据库升级前会保存一致性 `.backup-*` 副本。请定期备份持久化数据，恢复时停止服务后替换完整备份。

## 验证

```text
npm test
npm --prefix site test
npm --prefix site run build
```

自动测试使用独立 SQLite 和模拟邮件，覆盖认证、迁移、跨设备访问、账号隔离、保存冲突、配额、回收站和分享归属。它们不验证真实 SMTP 投递或公网 HTTPS 部署；上线前需用部署环境实际注册、收信，并在两个设备登录同一账号确认历史。
