# 课程讲义工坊网站设计

日期：2026-11-19
状态：待用户审核

## 目标

为课程讲义工坊增加一个面向不同学习者与内容创作者的独立网站。教师可以制作课堂讲义，学生可以整理课程内容和复习资料，自学者可以围绕主题规划学习路径。用户可以上传资料、生成并调整模块化大纲、选择需要的模块和内容深度，通过 DeepSeek 生成讲义，在浏览器中查看和编辑，运行现有讲义检查，下载 DOCX，或将阅读页面打印为 PDF。

网站免注册。私人讲义历史保存在本机浏览器，不上传到网站服务器；用户只有主动发布后，讲义才会进入可浏览、可分享的社区。社区公开内容需由服务器持久保存，因此网站使用数据库，但不建立个人账号系统。

## 目标用户

- 教师：根据课程目标和教学资料设计课堂模块、例题与习题，并分享可复用的讲义。
- 学生：整理课程笔记、制作复习提纲、选择需要重点学习的模块。
- 自学者及其他学习者：围绕感兴趣的主题规划学习顺序，按自身基础选择内容深度。

用户填写的“适用对象”用于描述讲义面向的学习者，不要求当前网站使用者必须是教师。表单、模块编辑器和社区功能使用通用措辞，不将核心操作限定为课堂教学。

## 使用流程

1. 用户填写主题、适用对象、模板、预期章节数和习题需求，可选上传已有资料。
2. 浏览器将资料发送至同源 Node API。服务器提取文本并尽快删除上传文件；用户确认后，提取出的相关文本会发送给 DeepSeek 用于大纲和内容生成。
3. 系统生成模块化学习大纲。用户可增删、重命名和排序模块、章节与小节，勾选需要的模块，并为讲义选择精简、标准或详细深度。
4. 浏览器向服务器请求生成所选内容。服务器逐章生成并发送进度事件，用户可查看进度并取消请求。
5. 浏览器以文档形式展示讲义，提供模块和章节导航。用户可以编辑正文、重新生成单个模块或章节、运行校验，并将讲义版本自动保存到本机历史。
6. 用户可下载 DOCX，或使用阅读页面的打印样式，通过浏览器“另存为 PDF”导出。
7. 用户可以将讲义主动发布到社区。社区访客可浏览和搜索已公开讲义；发布者可用专属管理链接编辑或撤回自己的分享，也可接收用户举报并由站点管理方处理。

网站不要求访客提供 DeepSeek API 密钥。私人历史只保存在本机浏览器；清除浏览器数据或更换设备后无法恢复。只有明确发布到社区的内容会保存在服务器。

## 方案比较

- 由 Node 后端调用 DeepSeek 和现有 Python 构建器。此方案复用项目的教学规范和文档输出，同时将 API 密钥保存在服务器端。推荐采用。
- 由静态前端直接调用 DeepSeek。这样会将 API 密钥暴露在浏览器中，不适合公开网站。
- 重新实现提示词、校验和文档渲染，会重复插件已有能力，并造成两边规格逐渐不一致。

## 架构

新增 `site/` 子应用，包含 React/Vite 浏览器端和 Node HTTP 服务器。Node 服务器托管构建后的前端，并提供同源 API。服务器从环境变量读取 DeepSeek 密钥和 Python 可执行文件路径。API 密钥不得出现在客户端资源、URL、错误信息或日志中。

网站与插件共用现有的 `course-handout/1` 文档格式和 Python 构建器。模板元数据目前定义在 `index.js` 中，应迁移到共享 JSON 模块，并由插件和网站共同读取，避免四种模板产生差异。现有工具名称、参数、输出 schema 和行为保持向后兼容。网站保存的私人历史和社区讲义均以该规格为版本化的数据格式。

在浏览器端增加模块化大纲编辑器。数据结构沿用模块—章—节树，支持增删、改名、排序、选择是否纳入当前讲义；内容深度设置作用于生成提示词和习题数量，不改变规格 schema。生成大纲和讲义时将用户资料作为参考上下文，并要求模型以资料为优先、标示资料未覆盖的补充内容，不得将资料原文大段复制进讲义。主题、对象和提示词应支持不同学习者场景，包括备课、课程复习和自主学习。

Node 服务器使用固定的可执行文件路径和参数数组启动 Python。服务器只在独立临时目录中写入提交的 JSON，调用现有的 `check` 或 `build` 命令，读取结果后删除临时文件。用户输入不得用于拼接 shell 命令。DOCX 作为下载响应返回。PDF 通过网站的打印样式由浏览器导出，网站服务不依赖 Office 或 LibreOffice。

使用 SQLite 持久化公开社区讲义、发布管理凭据摘要、举报记录和审核状态；生产环境须提供持久化磁盘。私人历史与未发布草稿不进入数据库。社区记录需包含来源规格版本、发布时间、匿名或可选展示名称、主题标签和状态。免登录发布会返回高熵管理令牌，令牌只向发布者显示一次，数据库仅保存令牌摘要；展示及搜索 API 永不返回令牌。发布者需保存管理链接才能编辑或撤回，丢失后无法自助找回。

### API 概览

- `GET /api/templates`：返回共享的模板元数据。
- `POST /api/handouts/generate`：接收主题和教学选项，流式返回生成进度事件及最终讲义规格。
- `POST /api/handouts/check`：接收讲义规格，返回 Python 校验结果和统计信息。
- `POST /api/handouts/docx`：接收已校验的规格，返回 DOCX 文件。
- `POST /api/materials/extract`：接收支持的文件，返回提取文本与文件名，不持久保存源文件。
- `GET /api/history` 不存在：私人历史只由浏览器 IndexedDB 管理，不经网站 API。
- `GET /api/community/handouts`：分页搜索已发布且可见的社区讲义。
- `GET /api/community/handouts/:id`：返回单份公开讲义。
- `POST /api/community/handouts`：发布讲义，返回一次性管理令牌。
- `PATCH /api/community/handouts/:id`、`DELETE /api/community/handouts/:id`：需提供该讲义的管理令牌。
- `POST /api/community/handouts/:id/reports`：提交举报。
- `POST /api/admin/community/handouts/:id/hide`：需提供仅保存在服务器环境中的管理员密钥，用于隐藏违规内容。

生成分为两步：先向模型请求精简大纲，再按章节请求正文。服务器会依据 `course-handout/1` 结构校验每次模型响应，并用 Python 校验器检查组装完成的规格。如果服务商返回的数据无效或不完整，服务器应返回清晰错误；校验器发现 error 时不得静默导出。浏览器可以取消正在进行的生成，并丢弃部分结果。

## 浏览器体验

首屏直接进入工作台，而不是产品介绍页。主要入口包括“新建讲义”“本机历史”和“讲义社区”。新建表单包含主题、适用对象、资料上传、模板、章节数量、习题需求等选项。大纲确认步骤展示可拖动排序的模块树、纳入讲义的选择控件，以及精简/标准/详细三档内容深度。编辑视图将模块导航与可读正文并列，并提供编辑、按模块或章节重新生成、校验、下载 DOCX、打印及发布到社区等操作。

本机历史列出讲义标题、主题、更新时间和校验状态，支持恢复、重命名、删除及导出；使用 IndexedDB 储存完整规格，容量异常时提示用户导出并清理旧版本。社区页提供搜索、主题筛选、讲义预览、举报和分享入口。发布确认需说明讲义将公开显示，并确认上传资料具有使用和分享权限。

阅读视图适配不同屏幕尺寸：窄屏下模块导航折叠为选择器，正文保持易读；打印样式隐藏交互控件，并保留文档标题层级和代码块。表单和模块树支持键盘操作，所有字段都有可访问标签。生成进度、资料提取、校验和发布状态清晰可见；错误显示在对应操作附近。

## 安全与滥用控制

- `DEEPSEEK_API_KEY` 只保存在服务器环境中。没有配置密钥时，网站仍可提供页面；生成请求返回清晰的服务器配置错误，直到密钥配置完成。
- 调用模型前限制请求体大小、主题与适用对象长度、章节数量，并校验所有枚举值。
- 资料上传仅支持可提取文字的 PDF、DOCX、PPTX、TXT 和 Markdown；首版不做扫描件或图片 OCR。限制单文件和总文件大小、页数、提取字符数及上传数量；拒绝宏和可执行内容。原文件只在隔离临时目录短暂保存并在处理后删除。
- 资料提取后向用户说明内容会发送给 DeepSeek。发送前提供预览和移除资料的操作；不把原始文件上传到模型服务。
- 按客户端 IP 限制匿名生成请求，并限制同时运行的生成任务数。只有在配置了可信代理时，才信任转发的 IP 请求头。
- 不记录提示词、生成的课程内容、API 密钥或临时文档内容。无论成功、失败还是取消，都要清理临时文件。
- API 只允许同源访问。向客户端返回通用服务商错误，不暴露密钥或上游原始响应头。
- 页面需提示访客：提交的主题和适用对象会发送给 DeepSeek 处理。
- 社区发布前须再次确认公开范围和资料授权。分享管理令牌不写入日志，举报与发布操作需做频率限制；社区页面提供举报入口。管理方可隐藏或删除违规内容，管理操作由服务端管理员密钥保护。

## 部署假设

生产环境运行 Node.js 与 Python 3.12，并安装 `python-docx`。部署时提供 `DEEPSEEK_API_KEY`；若 Python 不在 PATH 中，可配置 `PYTHON_PATH`。网站前端与 API 可由同一来源提供。另需 SQLite 和持久化磁盘，以保存已发布的社区内容及举报；不需要账号服务、Office 转换服务或对象存储。

目前项目没有指定的网站托管环境或域名。首版应支持本地开发和生产构建，并在 `site/README.md` 中说明部署要求。除非另行提出，网站部署本身不属于本次功能范围。

## 不在本次范围内

- 用户注册、账号、云端私人草稿、私人历史同步和协作功能。
- 服务器直接生成 PDF 文件；PDF 由浏览器打印保存。
- 付款、订阅、额度和管理后台。
- 社区发布以外的公开分享链接；未发布讲义和私人历史不在服务器永久保存。
- 修改现有插件工具契约。
- 社区私信、关注、点赞、评论和复杂的推荐系统。
- 扫描件和图片 OCR。

## 验收标准

- 教师、学生和自学者无需登录或提供 API 密钥即可使用网站；讲义自动保存到本机历史，刷新页面后可恢复。
- 网站提供与插件一致的四种模板，并允许设置适用对象、章节数量、习题需求和内容深度。
- 大纲编辑器支持模块、章节和小节的增删改名、排序与选择；只为选中的模块生成内容。
- 可上传并提取 PDF、DOCX、PPTX、TXT 和 Markdown 文本；生成结果能结合资料内容，并避免未标注的资料外扩展。
- 配置了有效的服务器 API 密钥后，生成过程会报告进度、产出有效规格，用户可在页面内查看和编辑讲义。
- 取消、服务商错误、模型 JSON 格式错误、Python 失败和校验错误均有清晰反馈，且不会清除页面中无关状态。
- 校验接口返回章节、小节和题目统计；存在 error 时阻止 DOCX 导出。
- DOCX 可以正常打开；阅读视图可通过浏览器打印生成可读 PDF。
- 社区访客可搜索和浏览已发布讲义；发布者可用专属令牌管理或撤回分享，访客可举报内容，管理员可隐藏违规分享。
- 私人草稿不会离开浏览器；只有用户明确发布的内容保存在服务器。分享令牌不暴露给其他访客且不写入日志。
- API 密钥不会出现在浏览器资源包、网络响应或日志中。
- `node --check index.js`、Python 编译、现有示例校验与构建、网站测试及前端生产构建全部通过。
- 现有插件工具保持向后兼容，四种模板只有一份定义来源。

## 验证计划

为请求校验、资料提取与限制、模型响应解析、频率限制、共享模板加载、本机历史和社区令牌校验编写单元测试。使用模拟的 DeepSeek 兼容响应运行 API 测试，覆盖成功生成、无效 JSON、服务商失败、取消请求和输出校验。运行现有 Python 校验与构建命令，并用 `python-docx` 确认 DOCX 可打开。使用临时 SQLite 数据库验证发布、搜索、编辑、撤回、举报和管理员隐藏流程，并确认私人历史不进入数据库。在本地运行网站，分别在桌面和手机宽度下验证资料上传、大纲模块选择、内容深度、历史恢复、社区分享、DOCX 下载和打印流程。真实 DeepSeek 连通测试应是可选项，只在本机显式配置 API 密钥时运行；CI 不依赖密钥，也不调用付费 API。
